# Johnny Builds to Mars

Parker & Pine's first interactive children's storybook for ages 6–10, built with only vanilla HTML, CSS, and JavaScript.

## Included

- One focused storybook page with a cover and arrow-controlled story slides
- Johnny spotting Mars, gathering supplies around the house, building in the garage while his dog judges him, blasting off, landing on Mars, and discovering he forgot snacks
- Interactive activities: wake Mars, pack supplies by tap or drag, build rocket parts, ask the dog for a verdict, hold to launch, explore Mars, and open the empty snack pouch
- Page 2 includes a starry space wallpaper behind a transparent drawing pad, so every rocket stroke is visible in space
- Page 2 includes a Clear entire pad action, and saved rocket parts appear on the right side of the garage scene
- The saved rocket displays on pages 2 and 3 are enlarged 3×, while page 5 shows it at 2×; page 4 is now a rocket-free Mars exploration scene
- The final slide replaces the open button with a drag-to-open snack pouch that reveals one crumb and “THE END”
- When fully opened, the pouch zooms in and separates its top and bottom flaps around the ending reveal
- The dog's speech bubble is attached to the dog and stays positioned with him on smaller screens
- A final “Read again? Click here” restart action
- Accessible labels, live feedback, focus states, reduced-motion support, and mobile layout
- No packages, build steps, external fonts, or network requests

## Run it locally

Open `index.html` directly in a browser, or serve this folder with any simple static server. It is intentionally self-contained.

## Deploy to GitHub Pages

1. Create a GitHub repository and add `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
2. Push the files to the default branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and the `/ (root)` folder, then save.
5. GitHub will publish the site at the Pages URL shown in that settings panel.

Because the project has no build process or server-side features, the root folder is ready to publish as-is.
